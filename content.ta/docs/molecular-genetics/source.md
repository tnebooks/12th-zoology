# அசல் பாடநூல் பக்கங்கள்: மூலக்கூறு மரபியல்

இந்தப் படங்கள் பாடநூலின் அசல் அமைப்பு, விளக்கப்படங்கள், குறிச்சொற்கள், அட்டவணைகள், செயல்பாடுகள் மற்றும் வினாக்களைப் பாதுகாக்கின்றன.
